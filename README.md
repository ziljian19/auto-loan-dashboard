# Auto Loan & Vehicle Research Dashboard

A React + Tailwind portfolio project simulating a vehicle financing intelligence platform. Built to demonstrate frontend engineering skills including dynamic calculations, data visualization with Recharts, and responsive UI design.

## Tech Stack

- **React** — component architecture, hooks (useState, useMemo)
- **Vite** — fast dev server and build tooling
- **Tailwind CSS** — utility-first styling with dark theme
- **Recharts** — area charts, bar charts, line charts

## Features

- **Vehicle Selector** — Choose from 4 makes, multiple models, years, and trim levels with cascading state
- **Live Loan Calculator** — Real-time monthly payment, total interest, and all-in cost based on inputs
- **Amortization Schedule** — Full paginated payment-by-payment breakdown
- **Loan Term Comparison** — Bar chart + table comparing all term lengths at once
- **Depreciation + Equity Tracker** — Estimated vehicle value over 5 years vs. remaining loan balance

## Getting Started

```bash
npm install
npm run dev
```
